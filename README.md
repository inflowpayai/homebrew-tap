# InFlow Homebrew Tap

Homebrew Casks for InFlow command-line releases.

## Install

```sh
brew tap inflowpayai/tap
brew install --cask inflow
```

## Update

```sh
brew update
brew upgrade --cask inflow
```

## Uninstall

```sh
brew uninstall --cask inflow
```

Release artifacts are published from `inflowpayai/inflow-cli` GitHub Releases.
